# Plan 11-02: Failed Record Retry Engine and Conservative Duplicate Review Endpoints

## Goal
Implement safe retry execution for failed ingestion records and an inspection endpoint for duplicate candidate pairs flagged by conservative resolution.

## Proposed Changes
1. **Schemas (`backend/app/schemas/admin.py`)**:
   - `IngestionRetryResponseDTO`, `DuplicateCandidateDTO`.
2. **Service (`backend/app/services/admin.py`)**:
   - `retry_failed_run(db, run_id)`: Extracts error items and re-attempts ingestion through `IngestionPipeline`.
   - `get_duplicate_candidates(db)`: Surfaces titles with multiple provider mappings or matching normalized names.
3. **Endpoints (`backend/app/api/v1/endpoints/admin.py`)**:
   - `POST /api/v1/admin/ingestion/runs/{run_id}/retry`
   - `GET /api/v1/admin/ingestion/duplicates`
   - Protected by `require_admin`.
