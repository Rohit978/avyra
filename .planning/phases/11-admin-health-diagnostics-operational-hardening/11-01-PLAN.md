# Plan 11-01: Ingestion Run Diagnostic Endpoints and Error Trace Viewing

## Goal
Implement admin endpoints to inspect historical ingestion runs, execution durations, processed counts, and full error details.

## Proposed Changes
1. **Schemas (`backend/app/schemas/admin.py`)**:
   - `IngestionRunDetailDTO` with duration calculation and error summary.
2. **Service (`backend/app/services/admin.py`)**:
   - `list_ingestion_runs(db, page, limit)`
   - `get_ingestion_run(db, run_id)`
3. **Endpoint (`backend/app/api/v1/endpoints/admin.py`)**:
   - `GET /api/v1/admin/ingestion/runs`
   - `GET /api/v1/admin/ingestion/runs/{run_id}`
   - Protected by `require_admin`.

## Verification
- Unit and integration tests in `backend/tests/test_admin_api.py`.
