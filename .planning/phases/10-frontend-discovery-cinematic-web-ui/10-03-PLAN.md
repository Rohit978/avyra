# Plan 10-03: Browse Pages, Search Results, and Media Detail View

## Goal
Implement catalogue browse routes (`/movies`, `/tv`, `/anime`), full search results page (`/search`), and comprehensive media detail view (`/media/[id]`) with tabs and integrated playback.

## Proposed Changes
1. **Browse Pages**:
   - `frontend/src/app/movies/page.tsx`, `frontend/src/app/tv/page.tsx`, `frontend/src/app/anime/page.tsx`: Grid listings with genre filters and pagination.
2. **Search Page**:
   - `frontend/src/app/search/page.tsx`: Displays query results or empty state.
3. **Detail Page**:
   - `frontend/src/app/media/[id]/page.tsx`: Detail page with Overview, Cast, Season/Episode selector, and embedded `<Player />`.
