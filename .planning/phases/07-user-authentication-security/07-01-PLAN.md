# Plan 07-01: User Model, Alembic Migration, and Security Utilities

## Goal
Implement the User model with role and status enums, create the Alembic migration `0004_user_authentication`, and build security utilities for Argon2id password hashing and JWT token management.

## Proposed Changes
1. **User Role Enum (`backend/app/models/enums.py`)**:
   - Add `UserRole` enum: `USER = "USER"`, `ADMIN = "ADMIN"`.
2. **User Model (`backend/app/models/user.py`)**:
   - `User` entity with `id` (UUID), `username`, `email`, `hashed_password`, `role`, `is_active`, `avatar_url`, and timestamps.
3. **Alembic Migration (`backend/alembic/versions/0004_user_authentication.py`)**:
   - Create `users` table with unique constraints on `username` and `email`.
4. **Security Utilities (`backend/app/core/security.py`)**:
   - `hash_password(password: str) -> str`: Uses Argon2id.
   - `verify_password(plain_password: str, hashed_password: str) -> bool`: Safe verification.
   - `create_access_token(data: dict, expires_delta: Optional[timedelta] = None) -> str`: JWT creation.
   - `decode_access_token(token: str) -> Optional[dict]`: Safe token decoding.

## Verification
- Unit tests in `backend/tests/test_security.py` verifying hashing, verification, token encoding and decoding.
