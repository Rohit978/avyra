# Plan 07-02: Registration, Login, and Logout API Endpoints

## Goal
Implement secure authentication endpoints (`POST /api/v1/auth/register`, `POST /api/v1/auth/login`, `POST /api/v1/auth/logout`, `GET /api/v1/auth/me`) with cookie and header token support.

## Proposed Changes
1. **Schemas (`backend/app/schemas/auth.py`)**:
   - `UserRegisterRequest`: `username`, `email`, `password`.
   - `UserLoginRequest`: `login` (email or username), `password`.
   - `UserResponseDTO`: `id`, `username`, `email`, `role`, `is_active`, `avatar_url`, `created_at`.
   - `TokenResponseDTO`: `access_token`, `token_type`, `user: UserResponseDTO`.
2. **Auth Service (`backend/app/services/auth.py`)**:
   - `register_user(db, req)`
   - `authenticate_user(db, login, password)`
3. **Auth Router (`backend/app/api/v1/endpoints/auth.py`)**:
   - Register `/register`, `/login`, `/logout`, `/me`.
   - Mount in `backend/app/api/v1/router.py`.

## Verification
