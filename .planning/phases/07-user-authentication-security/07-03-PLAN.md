# Plan 07-03: Profile Management & FastAPI Authentication Dependencies

## Goal
Implement profile update endpoints (`PUT /api/v1/auth/profile`) and reusable FastAPI dependencies (`get_current_user`, `get_current_active_user`, `require_admin`) for securing API routes.

## Proposed Changes
1. **Schemas (`backend/app/schemas/auth.py`)**:
   - `UserProfileUpdateRequest`: `username: Optional[str]`, `email: Optional[str]`, `avatar_url: Optional[str]`, `password: Optional[str]`.
2. **Dependencies (`backend/app/core/deps.py`)**:
   - `get_current_user`: extracts token from `Authorization: Bearer` header or `access_token` cookie, decodes JWT, queries User, raises 401 if invalid.
   - `get_current_active_user`: ensures user is active.
   - `require_admin`: ensures `user.role == UserRole.ADMIN`, raises 403 otherwise.
3. **Profile Endpoint (`backend/app/api/v1/endpoints/auth.py`)**:
   - `PUT /api/v1/auth/profile`: updates user profile attributes with unique check.

## Verification
- Automated tests in `backend/tests/test_auth_api.py` validating protected endpoints, 401 unauthenticated errors, 403 forbidden errors, and profile updates.
