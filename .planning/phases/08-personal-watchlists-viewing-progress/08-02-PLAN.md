# Plan 08-02: Viewing Status and Episode Progress Tracking Models and Endpoints

## Goal
Implement viewing status management (Plan to Watch, Watching, Completed, Dropped) and episodic progress tracking models and API endpoints.

## Proposed Changes
1. **Models (`backend/app/models/progress.py`)**:
   - `UserMediaProgress`: `user_id`, `media_id`, `status: ViewingStatus`, `rating: Optional[float]`.
   - `UserEpisodeProgress`: `user_id`, `media_id`, `episode_id`, `is_watched: bool`, `progress_seconds: int`.
2. **Schemas (`backend/app/schemas/progress.py`)**:
   - `MediaProgressUpdateRequest`, `MediaProgressResponseDTO`, `EpisodeProgressUpdateRequest`, `EpisodeProgressResponseDTO`.
3. **Service & Router**:
   - `backend/app/services/progress.py`.
   - `backend/app/api/v1/endpoints/progress.py`.
   - Mount under `/api/v1/progress` in router.

## Verification
- Automated tests in `backend/tests/test_watchlist_api.py`.
