# Plan 08-01: Watchlist & Watchlist Item Models and CRUD API Endpoints

## Goal
Implement the database models for watchlists and watchlist items, author Alembic migration `0005_watchlists_and_progress`, and build the complete CRUD API endpoints for managing personal watchlists and items.

## Proposed Changes
1. **Models**:
   - `ViewingStatus` enum in `backend/app/models/enums.py`.
   - `Watchlist` and `WatchlistItem` models in `backend/app/models/watchlist.py`.
   - Alembic migration `0005_watchlists_and_progress.py`.
2. **Schemas (`backend/app/schemas/watchlist.py`)**:
   - `WatchlistCreateRequest`, `WatchlistUpdateRequest`, `WatchlistResponseDTO`, `WatchlistItemAddRequest`, `WatchlistItemResponseDTO`, `WatchlistDetailResponseDTO`.
3. **Service & Router**:
   - `backend/app/services/watchlist.py`.
   - `backend/app/api/v1/endpoints/watchlists.py`.
   - Mount under `/api/v1/watchlists` in router.

## Verification
- Unit and integration tests in `backend/tests/test_watchlist_api.py`.
