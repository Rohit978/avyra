# Plan 09-03: Playback API Endpoints & Iframe Sandbox Directives

## Goal
Expose `GET /api/v1/media/{id}/playback-options` with optional `season` and `episode` query parameters, sandbox policies, and integration tests.

## Proposed Changes
1. **Endpoint (`backend/app/api/v1/endpoints/playback.py`)**:
   - `GET /api/v1/media/{media_id}/playback-options`:
     - Query params: `season: Optional[int]`, `episode: Optional[int]`.
     - Returns `PlaybackOptionsResponseDTO`.
     - Raises 404 if media does not exist.
2. **Mount in API Router**:
   - Register route under `/api/v1/media` or include in `backend/app/api/v1/endpoints/media.py`.

## Verification
- Automated integration tests in `backend/tests/test_playback_api.py`.
