# Plan 09-02: Parameterized URL Generator & Domain Allowlist Validation

## Goal
Implement allowlist verification and URL templating for movies and TV episodes with strict domain validation.

## Proposed Changes
1. **URL Generator (`backend/app/services/playback.py`)**:
   - `build_movie_urls(tmdb_id: str)`: Generates `vidbolt` and `reelsdownload` URLs.
   - `build_tv_urls(tmdb_id: str, season: int, episode: int)`: Generates `vidbolt` TV episode URL with `{s}` and `{e}`.
   - `validate_embed_domain(url: str)`: Verifies URL hostname against `settings.ALLOWED_EMBED_DOMAINS`.
2. **Fallback & Edge Cases**:
   - Discards URLs whose domain fails validation.
   - Formulates fallback response when TMDB ID is missing.

## Verification
- Unit and security tests in `backend/tests/test_playback_service.py`.
