# Plan 09-01: Playback Options Service & TMDB ID Resolution

## Goal
Implement the core `PlaybackService` resolving internal canonical media UUID to third-party TMDB IDs and assembling stream metadata.

## Proposed Changes
1. **Schemas (`backend/app/schemas/playback.py`)**:
   - `EmbedSourceDTO`: `id: str`, `name: str`, `embed_url: str`, `domain: str`, `is_primary: bool`.
   - `PlaybackOptionsResponseDTO`: `media_id: UUID`, `media_type: MediaType`, `title: str`, `has_stream: bool`, `tmdb_id: Optional[str]`, `season_number: Optional[int]`, `episode_number: Optional[int]`, `embed_sources: List[EmbedSourceDTO]`, `sandbox_policy: str`, `referrer_policy: str`, `reason: Optional[str]`.
2. **Service (`backend/app/services/playback.py`)**:
   - Resolves TMDB external ID from `ExternalID` table.
   - Handles movie vs episodic stream resolution.

## Verification
- Unit tests in `backend/tests/test_playback_service.py`.
