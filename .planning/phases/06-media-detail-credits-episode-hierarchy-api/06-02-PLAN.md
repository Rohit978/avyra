# Plan 06-02: Cast, Crew, and Credits Query Endpoints

## Goal
Implement the media credits endpoint `GET /api/v1/media/{id}/credits` delivering structured cast and crew lists with character names, jobs, and profile images.

## Proposed Changes
1. **Schemas (`backend/app/schemas/detail.py`)**:
   - `CastMemberDTO`: `id: UUID`, `person_id: UUID`, `name: str`, `original_name: Optional[str]`, `character_name: Optional[str]`, `profile_path: Optional[str]`, `order: int`.
   - `CrewMemberDTO`: `id: UUID`, `person_id: UUID`, `name: str`, `original_name: Optional[str]`, `department: Optional[str]`, `job: Optional[str]`, `profile_path: Optional[str]`.
   - `MediaCreditsDTO`: `cast: List[CastMemberDTO]`, `crew: List[CrewMemberDTO]`.
2. **Service (`backend/app/services/detail.py`)**:
   - `get_media_credits(db: AsyncSession, media_id: UUID) -> Optional[MediaCreditsDTO]`
   - Queries `Credit` joined with `Person`, ordered by `order` asc for cast and department/name for crew.
3. **Endpoint (`backend/app/api/v1/endpoints/media.py`)**:
   - Add `GET /api/v1/media/{id}/credits`. Returns 404 if media does not exist.
