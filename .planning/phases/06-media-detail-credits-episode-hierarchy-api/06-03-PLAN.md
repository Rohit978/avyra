# Plan 06-03: Season and Episode Navigation Endpoints with Provenance Metadata

## Goal
Implement structured season and episode navigation endpoints (`GET /api/v1/media/{id}/seasons`, `GET /api/v1/media/{id}/seasons/{season_number}`, `GET /api/v1/media/{id}/seasons/{season_number}/episodes/{episode_number}`) with ordered listings and episode metadata.

## Proposed Changes
1. **Schemas (`backend/app/schemas/detail.py`)**:
   - `EpisodeDTO`: `id: UUID`, `season_id: UUID`, `media_id: UUID`, `episode_number: int`, `title: Optional[str]`, `overview: Optional[str]`, `still_path: Optional[str]`, `air_date: Optional[date]`, `runtime: Optional[int]`.
   - `SeasonSummaryDTO`: `id: UUID`, `season_number: int`, `title: Optional[str]`, `overview: Optional[str]`, `poster_path: Optional[str]`, `air_date: Optional[date]`, `episode_count: int`.
   - `SeasonDetailDTO(SeasonSummaryDTO)`: includes `episodes: List[EpisodeDTO]`.
2. **Service (`backend/app/services/detail.py`)**:
   - `get_media_seasons(db: AsyncSession, media_id: UUID) -> List[SeasonSummaryDTO]`
   - `get_season_detail(db: AsyncSession, media_id: UUID, season_number: int) -> Optional[SeasonDetailDTO]`
   - `get_episode_detail(db: AsyncSession, media_id: UUID, season_number: int, episode_number: int) -> Optional[EpisodeDTO]`
3. **Endpoints (`backend/app/api/v1/endpoints/media.py`)**:
   - Add routes and register with 404 validation.
