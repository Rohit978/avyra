# Plan 06-01: Media Detail REST Endpoints and Response Schemas

## Goal
Implement the core media detail endpoint `GET /api/v1/media/{id}` returning complete metadata, genres, alternate titles, and external ID provenance with full 404 handling.

## Proposed Changes
1. **Schemas (`backend/app/schemas/detail.py`)**:
   - `ExternalIDDTO`: `provider: str`, `external_id: str`.
   - `MediaTitleDTO`: `title: str`, `title_type: str`, `language: Optional[str]`.
   - `MediaDetailDTO`: ID, title, original_title, overview, media_type, status, release_date, end_date, runtime, country_of_origin, original_language, popularity, vote_average, vote_count, poster_url, backdrop_url, genres, titles, provenance.
2. **Detail Service (`backend/app/services/detail.py`)**:
   - `get_media_detail(db: AsyncSession, media_id: UUID) -> Optional[MediaDetailDTO]`
   - Eagerly loads `genres`, `titles`, and `external_ids`.
3. **Endpoint (`backend/app/api/v1/endpoints/media.py`)**:
   - Add `GET /api/v1/media/{id}`. Returns 404 if not found.

## Verification
- Unit and integration tests in `backend/tests/test_media_detail_api.py`.
