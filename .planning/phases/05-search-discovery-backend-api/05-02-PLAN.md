# Plan 05-02: Search & Autocomplete API Endpoints

## Goal
Implement the FastAPI endpoints for media search and autocomplete suggestions (`GET /api/v1/search` and `GET /api/v1/search/suggestions`), with request validation, query parameters, debouncing considerations, and proper error handling.

## Proposed Changes
1. **API Router**:
   - `backend/app/api/v1/endpoints/search.py`:
     - `GET /api/v1/search`: Query params: `q` (min length 1), `media_type`, `genre`, `year`, `page` (default 1), `limit` (default 20, max 100).
     - `GET /api/v1/search/suggestions`: Query params: `q` (min length 1), `limit` (default 8, max 20).
2. **Main Application Routing**:
   - Mount search router under `/api/v1/search` in `backend/app/api/v1/router.py` and register in `backend/app/main.py`.

## Verification
- Unit and integration tests in `backend/tests/test_search_api.py` validating HTTP responses, status codes, query parameter parsing, empty results, and autocomplete responses.
