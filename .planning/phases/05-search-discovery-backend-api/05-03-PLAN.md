# Plan 05-03: Filtered Catalogue Browsing & Curated Collection Endpoints

## Goal
Implement the filtered media catalogue browsing endpoint (`GET /api/v1/media`) with multi-attribute filtering (media_type, genre, release year, status) and pagination, plus curated collection feeds (`GET /api/v1/media/curated/trending`, `/popular`, `/top-rated`, `/upcoming`).

## Proposed Changes
1. **Discovery Service**:
   - `backend/app/services/discovery.py`:
     - `browse_catalogue(db, media_type, genre, year, status, sort_by, sort_order, page, limit)`
     - `get_curated_trending(db, limit, page)`
     - `get_curated_popular(db, limit, page)`
     - `get_curated_top_rated(db, limit, page)`
     - `get_curated_upcoming(db, limit, page)`
2. **API Router**:
   - `backend/app/api/v1/endpoints/media.py`:
     - `GET /api/v1/media`: Catalogue browsing with filtering and sorting.
     - `GET /api/v1/media/curated/{collection}`: Trending, popular, top-rated, upcoming feeds.
     - Mount in `backend/app/api/v1/router.py`.

## Verification
- Automated tests in `backend/tests/test_discovery_api.py` verifying sorting, genre filtering, year filtering, and curated endpoints.
